# relieve — stand-up pouch artwork spec

Please check these values against your own dieline and tell us about any differences before printing.
We will move the artwork onto your template if your sizes are different.

## Pouch
| Item | Value |
|---|---|
| Type | Stand-up pouch (doypack), resealable zipper, round-corner option OK |
| Size (W × H) | 120 × 200 mm |
| Bottom gusset | 70 mm total (35 mm folded into each side) |
| Finish | Matte laminate preferred (soft-touch if available) |
| Quantity per pouch | Nasal strips 30 · Sleep tape 30 · Body patches 20 pairs |

## Artwork files
| File | Contents |

| `*-DIELINE-PROOF.pdf` / `proof-*.png` | Same art with guides: trim, bleed, seals, zipper, tear notch, gusset fold, safe area. **Do not print.** |

- Page size includes **3 mm bleed** on every side (front/back 126 × 206 mm, gusset 126 × 76 mm). TrimBox is set to the finished size.
- Guides used (typical values, please confirm): side seals 8 mm, top seal 10 mm, tear notch 25 mm from top, zipper 35 mm from top, safe area 4 mm inside the seals.
- The logo is vector outlines. Body text uses embedded fonts (Inter, Readex Pro, Bricolage Grotesque). Please tell us if you need all text converted to outlines.
- Artwork is supplied in RGB. Please convert to CMYK with your profile and send a colour proof before printing.
